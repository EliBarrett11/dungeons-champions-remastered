# Effect Catalogue Status

A catalogue of 240 named effect concepts was previously developed across these categories: offensive buffs, defense, healing/support, debuffs, control, damage-over-time, marks, resource/Ultimate effects, stacks/transforms, reactions/triggers, saves/cleanses, death/survival and battlefield effects.

**Important:** the 240 entries are conceptual design inventory, not 240 fully specified executable effects. Every implemented effect needs a stable ID, timing, target rules, duration, stacking, removal, operation, tags, balance metadata and test coverage. Do not generate generic handlers for every catalogue name without formalizing semantics.

The existing schema package includes effect, ability and Champion combat schemas, templates and illustrative examples. These files must be validated and reviewed before being treated as canonical.
